# club-analyzer — анализатор лекций клуба «Ты Боженька Продаж»

Инструмент Denis'а для разбора записей занятий: расшифровка через Whisper,
анализ через GPT, из этого собирается описание лекции — тезисы, главные идеи,
таймкоды. Есть вкладка дайджестов. Владелец — Denis, гуру продаж, **новичок в
программировании**. Отвечать по-русски.

## Что это

**Один файл `index.html` с CSS и JS внутри. Без сборки, не React.**
Данные тянет с того же бэкенда, что и остальные фронтенды —
`https://api.youselllikeagod-magazine.ru` (репозиторий `club-backend`,
приватный). Готовая разметка лекции уезжает туда же и дальше живёт в библиотеке
мини-приложения.

Рядом ещё два фронтенда в отдельных репозиториях: `club-app` (мини-приложение
участника) и `club-admin` (дашборд). **У всех трёх разные наборы классов и
вспомогательных функций** — перенося код между ними, проверять каждый класс по
таблице стилей ЭТОГО файла и каждую вызванную функцию по объявлениям ЭТОГО
файла.

⚠️ Файл трогают редко, и версия выложенного нигде не подписана. **Брать номер от
того, что реально лежит в репозитории**, а не по памяти.

## ⚠️ Обязательные проверки перед коммитом

1. **Синтаксис — только на склейке ЖИВЫХ блоков**, отобранных регуляркой
   `<script(?![^>]*\bsrc=)[^>]*>`: у тега с `src` содержимое браузером
   игнорируется, и код, случайно вложенный туда, никогда не исполнится.
2. **Инвентарь функций до и после** — «пропавшие» должно быть пусто.
3. **Цели `onclick` существуют** — grep с якорем `^function имя(`.
4. **`jsArg(v)` обязателен** для любого значения внутри `onclick="..."`.
   `JSON.stringify` там даёт двойные кавычки, первая закрывает атрибут, и клик
   молча перестаёт работать. Эта ошибка уже случалась в этом файле.
5. **Вложенность CSS проверять стеком**, а не счётом скобок: незакрытый
   `@media` уводит внутрь себя сотни правил, а счёт при этом сходится.

## Правила

- **Любой загрузчик, рисующий в DOM**: вызов отрисовки внутри `try`, запросу —
  таймаут. Иначе остаётся вечное «Загрузка…», которое не говорит ни о причине,
  ни о том, что вообще что-то сломалось.
- **Всё время в базе наивное и в UTC.** Наружу — только через хелперы бэкенда
  (`msk`, `_iso`), иначе врёт на три часа.
- **Долгие разборы могут идти минутами** — показывать состояние, а не молчать.

## Как работать с Denis'ом

- **Команды для терминала давать целиком, готовыми к вставке.** Не «поменяй
  строку» — он теряет пробелы и опечатывается.
- **Наполнение — не наша забота и напоминать о нём не надо.** Проектировать,
  считая, что материала будет достаточно.
- Он смотрит живьём и ловит то, чего не видно в коде. Скриншот от него стоит
  десяти гипотез.
- **Перед постройкой грепнуть файл**, даже будучи уверенным, что этого нет.
